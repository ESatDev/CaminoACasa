# 🐾 Camino a casa - Rescate independiente

Sitio web oficial para **Camino a casa**, una iniciativa independiente y red de hogares de tránsito enfocada en el rescate, rehabilitación y adopción responsable de perros y gatos en situación de abandono.

---

## 🌟 Características Principales

* **Filtro Dinámico de Mascotas:** Clasificación en tiempo real para filtrar entre perros, gatos o visualizar el catálogo completo.
* **Modal de Adopción Personalizado:** Ventana emergente interactiva que facilita la solicitud de adopción directamente a Instagram.
* **Gestión de Donaciones:**
  * Copia rápida al portapapeles del **ALIAS** (`Caminoacasa.ok`) y **CBU** (`0000076500000013575700`).
  * Información clara sobre puntos de acopio presenciales en veterinarias asociadas y recepción de insumos.
* **Diseño Moderno & Glassmorphism:** Barra de navegación fija translúcida, efectos hover interactivos y animación de entrada (*fade-in*) al hacer scroll.
* **Totalmente Responsive:** Adaptación completa a dispositivos móviles mediante menú hamburguesa responsivo.
* **Acceso Directo:** Botón flotante permanente para conectar con la comunidad en Instagram (`@caminoacasa.ok`).

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Marcado semántico y accesible.
* **CSS3:** Variables CSS, Flexbox, CSS Grid y animaciones personalizadas.
* **JavaScript (ES6+):** Manipulación del DOM, API Clipboard e Intersection Observer.
* **FontAwesome 6 & Google Fonts:** Iconografía vectorizada y tipografía *Plus Jakarta Sans*.

## 🚀 Instalación y Despliegue

Este proyecto no requiere de entornos de compilación ni dependencias externas pesadas.

1. **Clonar el repositorio:**
```bash
git clone [https://github.com/ESatDev/camino-a-casa.git](https://github.com/ESatDev/camino-a-casa.git)

```


2. **Ingresar al directorio:**
```bash
cd camino-a-casa

```


3. **Ejecutar:**
Abre el archivo `index.html` en cualquier navegador web o utiliza la extensión *Live Server* en Visual Studio Code.
